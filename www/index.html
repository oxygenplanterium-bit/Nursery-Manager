Daily report send

Every day at 8:00 PM the day's report is sent to these emails and WhatsApp numbers. One entry per line. WhatsApp numbers need the country code, digits only, for example 919876543210.

Owner WhatsApp number

When a supervisor requests new items, they get a one-tap WhatsApp message addressed to this number. Everyone who opens the register can see it. Include the country code, digits only, for example 919876543210. Leave it empty to turn this off.
